# Weekmark for Windows v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows version of Weekmark whose v1 is the always-visible desktop widget, a tray icon showing the week
number, settings and first-run, built and released from GitHub Actions and runnable from source.

**Architecture:** A UI-free C# core library (`Weekmark.Core`) ports the Swift `Sources/CWCore` logic and is proven
identical to it by a JSON file of expected answers generated from the Swift side. An Avalonia app
(`Weekmark.App`) draws the widget, tray icon and windows on top of the core; Windows-only behaviour (desktop layer,
startup, tray theme) sits behind small interfaces with no-op fallbacks, so the app also runs on the Mac for
development.

**Tech Stack:** .NET 10 SDK, C#, Avalonia 11 (+ Avalonia.Headless.XUnit for render tests), CommunityToolkit.Mvvm,
xUnit, Velopack (per-user installer, portable zip), GitHub Actions (`windows-latest`, `ubuntu-latest`), Swift/XCTest
(vector export only).

**Spec:** `specs/2026-10-25-windows-design.md` (approved). Read it before starting any task.

## Global Constraints

- Never disagree with the Mac app on week numbers, holidays, working days, sprint/PI/quarter labels or copy text: every core behaviour is checked against `Tests/vectors/cwcore-v1.json`.
- Week numbering options on Windows: ISO and US only. No "System". A `numbering` value of `system` read from settings is treated as ISO.
- Default numbering: ISO, or US when the Windows region is the United States (decided at first run).
- Dates and copy text are English. Month-first for en-US, day-first otherwise ("CW46 (9–15 Nov)", "CW1 2027 (28 Dec – 3 Jan)").
- Windows 10 22H2 and Windows 11, x64 and ARM64. Mica/acrylic on Windows 11; acrylic or solid on Windows 10.
- Install and run without admin rights. Self-contained: no .NET install needed by users.
- Settings: `%APPDATA%\Weekmark\settings.json`, same keys and JSON shapes as the Mac (`numbering`, `size`, `layer`, `background`, `appearance`, `showMonth`, `showProgress`, `showPlanning`, `showMilestones`, `showInMenuBar`, `locked`, `onboardingDone`, `sprint`, `quarter`, `milestones`, `regions`, `customHolidays`, `screenID`, `offsetX`, `offsetTop`), plus Windows-only `startWithWindows`.
- Widget sizes: Small 0.8, Medium 1.0, Large 1.3, Extra Large 1.7 (scale of a 300 px-wide base layout, as on the Mac).
- No network access in v1. No tracking.
- Anything captured automatically (CI screenshots, test renders) uses sample data, never the user's settings file.
- Idle working set target: under about 100 MB, measured on CI and reported per build (a warning, not a failure).
- Windows releases use tags `windows-v<version>` (starting `windows-v0.1.0`), are created with `--prerelease --latest=false`, and never become the repo's latest release.
- No Quick Finder text field, lookup hotkey, Year button or update checks in v1 (they are v2).
- The Mac/iOS apps don't change, except Swift core bug fixes found while porting (fix in Swift with a test, regenerate vectors).

## Review Focus

1. **Monitor unplugged, or a monitor left of/above the primary (negative coordinates), or 125–200 % scaling:** the widget comes back on its saved monitor when present, otherwise lands fully visible on the primary monitor, never off-screen. Pinned by Task 8 tests.
2. **A corrupt, empty, hand-edited or newer-version `settings.json`:** the app still starts (defaults), keeps a backup of the bad file, and never drops keys it doesn't understand when saving. Pinned by Task 7 tests.
3. **Midnight, sleep/resume, or a time-zone change while running (Sunday → Monday is a new week):** widget and tray update to the new week without a restart. Pinned by Task 6 (`WeekClock`) and Task 9 wiring.
4. **Messy company `.ics` files (UTF-8 BOM, CRLF or LF, folded lines, `TZID=`/`VALUE=DATE` parameters, missing `DTEND`, multi-day and absurdly long events):** imported without crashing, same days as the Mac. Pinned by Task 4 vectors.
5. **Weekmark launched twice (start-with-Windows plus a manual double-click):** one instance only; the second launch brings the widget forward and exits. Pinned by Task 9 test.
