The third test build of Weekmark for Windows. This is a pre-release for colleagues to try. The Mac app's download is unaffected.

## What's new

- **Automatic updates.** An installed copy checks for a new version a minute after it starts, then once a day. When one
  is ready, the menu shows **Restart to Update to {version}**. If you don't click it, the update installs the next time
  Weekmark starts.
- **Check for Updates…** in the tray and widget menus, and **Check Now** in Settings → General → Updates.
- **Check for updates automatically** in the same place turns the daily check off.

## Install this one by hand

0.2.0 can't update itself. Install 0.3.0 from the Setup or Portable download once, as before. From then on updates
arrive on their own.

## Privacy

The daily check is the only network request Weekmark makes. It asks GitHub about this project's releases and downloads
new versions from GitHub. GitHub sees your IP address; nothing else is sent. The
[privacy page](https://rockykusuma.github.io/weekmark/privacy.html) says the same.

Setup, Portable, x64 versus ARM64 and the unsigned-build warning work as in 0.1.0: see the
[0.1.0 notes](https://github.com/rockykusuma/weekmark/blob/windows-v0.1.0/Windows/release-notes/0.1.0.md).
