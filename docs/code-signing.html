Weekmark for Windows

Code signing policy

Weekmark is free, open-source software (MIT licence). This page describes how its Windows programs are built and signed, so you can tell a genuine copy from a tampered one.

What is signed

The Windows programs and libraries of Weekmark (Weekmark.exe, its .dll files and the installer) published on the Releases page. Windows releases are tagged windows-v*.

How they are built

  • Signed binaries are built only by GitHub Actions, on GitHub-hosted runners, from tagged commits of the public repository rockykusuma/weekmark.
  • The build recipe is the public workflow .github/workflows/windows.yml. Nothing is built or signed on a personal computer.
  • Only builds that passed the automated tests are signed.

Roles

  • Author and committer: Rakesh Kusuma
  • Reviewer: Rakesh Kusuma
  • Approver of signing requests: Rakesh Kusuma

Weekmark has a single maintainer. Every signing request is approved by hand.

Privacy

Weekmark collects and transmits no personal data. It has no accounts, no analytics and no telemetry.

Unsigned builds

Until code signing is approved, Windows builds are unsigned and Windows SmartScreen may show "Windows protected your PC". You can always build Weekmark from source.

Report a problem

If you believe a signed Weekmark file is not genuine, please open an issue.
